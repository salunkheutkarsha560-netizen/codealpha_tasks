
# Simple Calculator in C

## Project Overview
This project is a simple command-line calculator developed using the C programming language. It performs basic arithmetic operations based on the user's choice.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Input validation for numbers and operation choice
- Division-by-zero protection
- Clear error messages for invalid choices

## Technologies Used
- C programming language
- GCC compiler
- Visual Studio Code

## How to Compile
Open a terminal in the project directory and run:

```bash
gcc calculator.c -o calculator
```

## How to Run
On Windows PowerShell, run:

```powershell
.\calculator.exe
```

## How to Use
1. Enter the first number.
2. Enter the second number.
3. Choose an operation from 1 to 4.
4. View the result.

## Operations
| Choice | Operation |
|---|---|
| 1 | Addition |
| 2 | Subtraction |
| 3 | Multiplication |
| 4 | Division |

## Error Handling
The program checks for invalid numeric input, invalid operation choices, and division by zero.
